# Gunjan Di — Birthday Website 🎂❤️

## Run
Open `index.html` in a browser.

## Change the password
Open `script.js` and change:
const correctPassword = "gunjan";

## Add photos
In `index.html`, replace each:
<div class="photo placeholder">YOUR PHOTO 01</div>

with:
<div class="photo"><img src="photos/photo1.jpg" alt="Gunjan Di"></div>

Then add this CSS if needed:
.photo img { width:100%; height:100%; object-fit:cover; border-radius:12px; }

## Put it online
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and your `photos` folder.
3. Deploy the repository with Vercel or GitHub Pages.
4. Send the resulting HTTPS link to Gunjan Di.
